# 化工产品助剂单机样品申请信息系统

这是一个专为化工行业销售、技术支持及客户经理开发的**单机版样品申请与客户随航管理系统**。系统基于 Python 自带的 `tkinter` 框架开发，无须复杂的网页服务器配置，开箱即用。它能帮助您高效记录客户索样信息、追踪样品测试状态、管理现场留档照片，并支持一键导出符合排版要求的 Excel 报表。

---

## 核心功能

*   **通用化助剂管理**：支持各类化工助剂（如流平剂、消泡剂、分散剂、固化剂等）的型号、数量及客户特殊要求的录入。
*   **智能输入补全**：内置历史客户公司名称自动联想匹配功能，随着使用时间的增加，录入效率加倍。
*   **样品照片留档**：支持关联本地样品或实验结果照片，在记录列表双击即可直接调用系统看图软件打开。
*   **全生命周期追踪**：支持“已申请、已寄出、测试中、测试通过、测试未通过”五种状态的实时更新与条件检索。
*   **智能 Excel 报表导出**：集成了 Pandas 数据处理引擎，导出时自动按“录入时间”进行降序排行，生成排版美观的 Excel 电子表格。
*   **本地轻量化存储**：采用 SQLite 嵌入式数据库，数据完全保存在本地（`coatings_samples.db`），保障商业机密安全。

---

## 系统界面预览与架构

本系统采用经典的高内聚单窗口结构，分为“信息录入区”、“状态控制与检索区”以及“历史看板数据表格区”：

*   **数据流向**：
    `用户交互 (Tkinter UI) ➔ 业务逻辑控制层 ➔ 本地嵌入式数据库 (SQLite3) ➔ 报表渲染输出 (Pandas/Openpyxl)`

## 快速开始

### 1. 环境依赖
系统核心功能基于 Python 标准库开发，但如果您需要使用 **Excel 报表导出** 功能，请确保您的计算机上安装了 `pandas` 和 `openpyxl` 库。

请在您的终端（Terminal）或命令提示符（CMD）中运行以下命令进行安装：
```bash
pip install pandas openpyxl

### 2. 运行程序
将代码保存为 sample_manager.py，然后在本地环境中执行：
```bash
python sample_manager.py
###系统在首次运行时，会自动在当前目录下创建名为 coatings_samples.db 的数据库文件。

### 操作指南
1. 录入样品申请
在顶部表单中填写客户公司（支持历史联想）、联系人、联系电话。

输入助剂型号和索样数量。

（可选）点击“上传样品照片”按钮，关联一张该样品的本地物理路径或实验看板图。

在“备注/要求”中填写客户的具体技术指标或反馈，点击提交申请。

2. 状态追踪与查询
检索：在“查询客户”输入框中输入客户公司关键字，点击“搜索”即可模糊查询；点击“显示全部”可重置列表。

更新状态：在下方表格中单击选中某条记录，在上方下拉菜单中选择最新的进展状态（例如“已寄出”或“测试通过”），点击更新状态即可。

3. 查看留档照片
在下方的历史记录表格中，双击任意一条包含照片路径的记录，系统将自动调用您电脑默认的图片查看器打开该图片。

4. 导出 Excel 报表
点击右侧橙色的导出 Excel 报表按钮，系统会自动将所有数据读入内存，清除临时缓存，并按时间最新的记录在前的顺序重新进行排行，最后弹出保存对话框供您选择下载位置。
